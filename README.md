# Los Reinoso Shopping

Sitio web estático de una tienda de compras enfocada en ropa, calzado, maquillaje y artículos para el hogar. El proyecto está desarrollado con HTML y CSS, y presenta una interfaz moderna para una experiencia de compra agradable y clara.

## Descripción

Los Reinoso Shopping es una tienda en línea que busca ofrecer una experiencia de compra sencilla y visualmente atractiva. El sitio incluye páginas de inicio, nosotros, productos, contacto, inicio de sesión y registro, con una navegación clara y un diseño coherente.

## Características

- Diseño responsive y adaptable a distintos tamaños de pantalla
- Navegación con menús y enlaces internos
- Sección de presentación de productos por categorías
- Página institucional con misión, valores y propósito de la marca
- Formulario de contacto para consultas e información
- Acceso para usuarios con páginas de login y registro
- Estilo visual consistente con una paleta elegante en tonos negros y dorados

## Tecnologías utilizadas

- HTML5
- CSS3
- Imágenes SVG y PNG para los elementos visuales
- GitHub Pages para posible despliegue del sitio

## Cómo ejecutar el proyecto

Como es un sitio estático, no requiere instalación de dependencias ni un servidor complejo. Puedes abrir cualquiera de los archivos HTML directamente en el navegador o ejecutar un servidor local simple.

### Opción 1: abrir directamente

1. Abre `index.html` en tu navegador.
2. Navega por las páginas del sitio usando el menú superior.

### Opción 2: servidor local

Desde la carpeta del proyecto, puedes ejecutar una pequeña opción local con Python:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```

## Páginas principales

- `index.html`: portada principal con mensaje promocional y categorías
- `nosotros.html`: información sobre la historia, misión y valores
- `productos.html`: catálogo y resumen por categorías
- `contacto.html`: formulario y datos de contacto
- `login.html`: acceso para clientes registrados
- `registro.html`: formulario de alta de usuario

## Objetivo del proyecto

Crear una tienda web estática que simule una experiencia de compra digital para un negocio comercial, demostrando buenas prácticas de maquetación, diseño visual y organización del contenido en una página web.
